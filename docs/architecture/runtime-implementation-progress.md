## Immediate sequence

1. Review authenticated quota-policy binding and multi-process reservation before any Control API wiring.
2. Define transport identity, privilege and operation revalidation requirements for a broker service; do not implement IPC until named-pipe identity and ACL decisions are reviewed.
3. **Store primitive added locally:** schema v3 transactionally binds Guest event receipts to the host's current Computer generation and active Lease before durable dedupe/append. It is not a receiver and must only be called after a future authenticated transport verifies identity.
4. **Cross-process duplicate Guest delivery verified:** eight child processes serialize one message to a single receipt. Continue filesystem/provider crash-boundary testing before wiring Scheduler or event intake to any Control API.
5. Keep the feature branch and PR Draft until these boundaries are reviewed. Do not merge anything or mark Proposed ADRs accepted.
