# Acceptance Criteria

Statuses: `NOT_STARTED`, `IN_PROGRESS`, `BLOCKED`, `VERIFIED`. Every `VERIFIED` item must link to reproducible evidence in `docs/progress.md`.

## Phase 2 — Secure Runtime API

| ID | Acceptance criterion | Status | Evidence |
|---|---|---|---|
| API-01 | Runtime API binds only to loopback, uses expiring session-scoped bearer capabilities, validates Host/Origin, and cannot bypass Gateway approval | VERIFIED | `node --test test/runtime-api.test.mjs`: 11/11, including isolation of run listing, lifecycle events, SSE and stop operations across credentials, preservation of lifecycle events emitted while a start request is still resolving, scope separation/revocation, loopback binding, Host/Origin rejection, and the default-deny Gateway boundary. Local Windows Node 24.13.0 `npm test`: 448/448; `npm run arch`: 76 paths / 0 violations; `npm run smoke`: pass. GitHub Actions run 40466146651 passed all six Windows/macOS/Linux × Node 22/24 test and architecture jobs. |
| API-02 | Run/event responses are field-projected; request body, event-stream cursor, client count, lifetime and buffering are bounded | VERIFIED | Local `node --test test/runtime-api.test.mjs`: session-local event IDs stay dense when Gateway events interleave across sessions; the no-journal ring is capped at 256 events/session and 256 session logs, SSE reconnect uses the session cursor, and a transient Gateway event-read failure is recoverable. GitHub Actions run 40470765335 passed tests and architecture checks across Windows/macOS/Linux × Node 22/24. Additional local evidence is recorded in the latest `docs/progress.md` row. |
| API-04 | A scoped, read-only provider catalog reports profile-only and unavailable states without probing or launching a provider | VERIFIED | Local Windows Node 24.13.0 `node --test test/runtime-api.test.mjs`: 19/19, including provider-catalog scope denial, exact projection, consistency against `buildProviderLaunch`, and no Gateway calls. Full `npm test`: 464/464; `npm run arch`: 77 paths / 0 violations; `npm run smoke`: pass. Catalog reports Claude as `argv-only`/`profile-only`, with Codex and OpenCode unavailable; it does not claim installed CLI compatibility. Cross-platform Actions pending. |
| API-03 | Production host/UI, explicit approval UX, provider input, persistent audit/recovery and crash-safe process ownership are implemented and cross-platform verified | IN_PROGRESS | Optional host-injected JSONL journal persists redacted start/stop decisions and allowlisted lifecycle events. API restart replays events and restores up to 64 recent runs under the same host-reissued session ID; unfinished runs are marked `interrupted` and cannot be stopped through the new Gateway. Startup rejects duplicate, skipped, or reversed per-session event IDs without modifying the journal; focused malformed-journal regression tests cover this integrity gate. Production host/UI integration, approval UX, provider input, real process restart recovery, retention/backup policy, and Guardian failure/PID reuse remain incomplete. |
