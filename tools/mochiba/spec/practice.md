# 持ち場 v1.2: 説明の練習 (道を指して答える)

## 目的

「AI が作った物を自分や人に説明できない」を、地図を指して答える練習で減らす。
言葉にする前に、どの箱を通るかを指せるかで「分かっているか」を確かめる。答え合わせは地図のデータでする (AI 不要)。
 2 案のモックから選んだ (2026-11-24、2 案以上のモックを見比べて)。

## 問いの作り方 (紙芝居ごと。2 通り)

1. **地図から自動 (AI 無し)**: 紙芝居 1 本につき最大 3 問。順番は自由で、全部押せば正解の「集まりの問い」
   - 「この PR で変わった箱はどれ？全部押して」(変わった箱が 2 個以上の時)
   - 「変わった『データの形』の箱にある道具 X を使っている箱はどれ？」: 変わった shared の箱へ入る import の名前のうち、3〜6 箱が使う物を 1 つ (変わった箱が多く使う物を先に、次に関数を定数より先に、次に使う箱が多い物、最後に名前順)。名前の一覧が全部を言っていない線 (一覧が切れた・`import * as`・丸ごと読み込み・名前の無い共通の入れ物) があれば、その名前は確かでないので選ばない
   - 「『X』が使っている箱はどれ？」: 変わった箱を行数の多い順に見て、使う箱が 2〜6 個の最初の箱
2. **AI に書かせた JSON**: `--story` の各紙芝居に `questions` を足す。どの AI が書いても同じ形
   - 「道の問い」(`path`): 箱を順に押す。順番も答え合わせする
   - 「集まりの問い」(`set`): 順番は自由
   - JSON の問いがある紙芝居では、それを先に出し、自動の問いを後ろに足す (合わせて最大 8 問)

```json
"questions": [
  { "ask": "店の人が撮った写真が Worker に着いた。そこから AI まで、どの箱を通る？",
    "how": "Worker の入口の箱から順に押す",
    "path": ["entry:入口と守り", "entry:お客さんのリンク", "adapter:AI の読み取り", "outside:AI (Claude)"],
    "says": ["askModel", "callModel ×2", "Haiku と Sonnet"],
    "side": ["shared:名簿"],
    "answer": ["Worker の入口が受け取り、2 つの AI を同時に呼ぶ", "1 つ目は名簿に入る答え、2 つ目は確かめ役"],
    "names": ["askModel"], "files": ["worker/ask.mjs"], "note": "任意の 1 行" },
  { "ask": "validateReading を使っている箱はどれ？", "set": ["adapter:AI の読み取り", "core:AI の読み取り"], "answer": ["..."] }
]
```

- `path` は 2〜8 箱、同じ箱は 2 回出さない。`says` は隣どうしの間の言葉 (任意)。`side` は寄り道 (押しても数えない)
- 答えの箱 (path / set) に地図に無い箱を 1 つでも含む問いは、まるごと捨てて「注意」に出す (答えが変わってしまうため)。寄り道 (side) の地図に無い箱は、その箱だけ外して「注意」に出す。ファイルは紙芝居と同じ扱い
- 同じ答えの箱の問いが 2 つあれば最初の 1 つだけ使う。9 個以上あれば最初の 8 個だけ使い、「注意」に出す (検査で捨てた分は数えない)

## 答え合わせ (地図のデータと比べるだけ)

- 道の問い: 押した順のうち、答えの順に沿っている一番長い並びを「合っている」。答えにあるが順番が外れた箱は「順番が違う」、寄り道は「寄り道 (数えない)」、答えに無い箱は「道の外」、押していない答えの箱は「抜け」(点線)
- 集まりの問い: 押した箱が答えにあれば「合っている」、無ければ「道の外」、押していない答えの箱は「抜け」
- 点数は出さない

## 画面

- 上の帯に「練習」ボタン (問いが無い時は出さない)。押すと、問いのある一番上の紙芝居の 1 問目から
- 練習の間:
  - 下に札: 問い・押し方・押した順 (番号付き)・「1 つ戻す」「やり直す」「答え合わせ」
  - 地図の箱を押すと、その箱が次の番号で選ばれる (もう一度押すと外れる)。箱の欄は開かない
  - 答え合わせの後: 箱に結果の札、答えの道の線が光る (線の上に says)、答え 2 行・名前 (小さく)・ファイル・補足。続けて「自分の言葉で 1 回言ってみる」と 言えた / あいまい / 言えなかった
  - 右の欄: この紙芝居の問いの一覧 (状態つき)、「もう一度」の一覧、ほかの紙芝居
- 「あいまい」「言えなかった」はこのブラウザに日付と一緒に残す。次の日から「もう一度」の一覧の上に出る。「言えた」で外れる。記録は問いの文が同じ時だけ使う (JSON を書き直して問いが変わったら、古い記録は出さない)
- URL に `#quiz=<紙芝居の key>&q=<n>` を残す
- Esc で閉じる。紙芝居・箱の欄・一覧を開くと練習は閉じる
