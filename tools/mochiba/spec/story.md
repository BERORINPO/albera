# 持ち場 v1.1: 地図の上の紙芝居

## 目的

PR 1 本で何が起きたかを、地図の上で 1 コマずつ追って説明できるようにする。
「地図の上で追う型」を選んだ (2026-11-24、2 案以上のモックを見比べて)。

## コマの作り方 (2 通り。AI は mochiba の中では使わない)

1. **自動 (いつも作る)**: この期間の PR ごとに 1 本。AI を使わず、git と表から作る
   - 1 コマ目「変わった箱」: その PR で変わったファイルを含む箱を全部光らせる
   - 2 コマ目から: 変わった箱を 1 つずつ、入口 → 外とのつなぎ → 中身の決まり → データの形 の順に。その箱と、同じ PR で変わった箱どうしの線を光らせる。文は「<層> の「<箱>」で 2 ファイル変わった (+60 −2)」の形
   - 最後のコマ「証拠」: PR の CI の結果と理由 (gh が取れた時)
   - 変わった箱が 8 個を超える PR は、行数の多い 8 個までにして「ほか N 箱は一覧で」と書く
   - PR を通っていない commit は、まとめて 1 本 (「PR なしの変更」)
2. **AI に書かせた JSON (任意)**: `--story <file.json>`。Copilot・Codex・Claude のどれが書いても同じ形
   - 同じ PR の自動の紙芝居と差し替える。PR が無い物は先頭に足す
   - 書かせ方: 紙芝居の右の欄の「AI に書かせる文をコピー」で、形・箱の名前・線の一覧・PR の題を含む頼み文が手に入る

### `--story` の JSON の形

```json
{
  "pr": 183,
  "title": "申込書の写真を 2 つの AI で読む",
  "steps": [
    {
      "title": "写真を作る",
      "say": "店の人が書類を撮り、健康の欄を塗った写真を作る",
      "boxes": ["entry:予約の取り込み", "adapter:AI の読み取り"],
      "lead": "entry:予約の取り込み",
      "lines": [{ "from": "entry:予約の取り込み", "to": "adapter:AI の読み取り", "say": "写真を渡す" }],
      "names": ["makePhoto", "photoPrep.prepare"],
      "files": ["js/intake-photo.js"],
      "note": "任意の 1 行"
    }
  ]
}
```

- 1 本だけなら上の形、何本もなら `{ "stories": [ ... ] }`
- 箱は地図の箱の id (`<役割>:<箱の名前>`)。線は from → to の箱 id。地図に同じ向きの線があればそれを光らせ、逆向きだけあれば逆向きに光を流し、どちらも無ければ点線で描いて「地図に無い線」と添える
- 読めない JSON・形が違う時は exit 1 と直し方 1 行。中身の一部が地図と合わない時 (無い箱・地図の外のファイル) は、その部分だけ捨てて「注意」に出し、残りで作る
- 文字は全部 textContent で描く。長さの上限: title 40 字・say 200 字・names 12 個・steps 30 コマ。超えた分は切る

## 画面

- 上の帯の右に「紙芝居」ボタン (紙芝居が無い時は出さない)。箱の欄の PR の札にも「紙芝居で見る」
- 紙芝居の間:
  - 下に札: コマ番号・**普通の言葉の 1 文 (大きく)**・使う名前 (コードの名前、小さく)・ファイル (押すと VS Code で開く)・前へ / 次へ
  - 右の欄: PR を選ぶ所 (2 本以上の時)・コマの一覧 (押すと飛ぶ)・頼み文のコピー・閉じる
  - 地図: そのコマの箱だけ光らせ、主役の箱に枠。線は光の粒が流れ、線の上に say を書く。他は薄くする。コマを変えると、札に隠れない所へ寄る
  - キー: → / Space = 次、← = 前、Esc = 閉じる
  - URL に `#story=<PR番号 or nopr>&step=<n>` を残す (開き直すと同じコマ)
- 箱を押すと紙芝居を閉じて、いつもの箱の欄に戻る
